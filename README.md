# Aimz Red Soul Phantom — v2.3

## META fix

This release fixes the BetterDiscord error:

**META was not found.**

The BetterDiscord theme metadata block is now the **first content in the CSS file**, before any imports or CSS rules.

The theme is also standalone and does not require FrostedGlass.

## Folder

```text
Aimz-Red-Soul-Phantom-v2.3/
├── Aimz-Red-Soul-Phantom.theme.css
├── README.md
├── theme.json
└── assets/
    ├── soul-phantom-blade.jpg
    └── README.txt
```

## Install

For BetterDiscord:

1. Open Discord.
2. Go to **User Settings → Themes**.
3. Click **Open Themes Folder**.
4. Copy `Aimz-Red-Soul-Phantom.theme.css` and the `assets` folder into the Themes folder.
5. Enable **Aimz Red Soul Phantom**.

Keep:

```text
Aimz-Red-Soul-Phantom.theme.css
assets/
└── soul-phantom-blade.jpg
```

together.

## Dependencies

None.

The theme does not import FrostedGlass, ServerColumns, RadialStatus, Windows Titlebar, or Discolored.

The normal Discord Home icon is preserved.
